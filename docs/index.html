How SQUINT Works • MDL Transducer Math & Formats

        

        
      

      

        

          

            
            
            
          

          
        


        

          

            

              Stage 0 — Single-Sequence Null M0 & Reading-Frame QA
              Fixed-Share Repeat + Dirichlet-Multinomial
            

            

              Before aligning any pair, SQUINT compresses each sequence independently under a causal sequential encoder combining smoothed empirical composition with 12 Fixed-Share periodic repeat experts. Homopolymer runs and tandem SSRs receive near-zero surprise under M0 so low-complexity composition never mimics homology.
            

            
L₀(X) = L_N(|X|) + Σᵢ −ln M₀(xᵢ | X_{<i}) nats

          


          

            

              Stage 1 — Component Partitioning, Frameshift Repair & BioNJ
              ΔL_hom > 0 nats Decision Boundary
            

            

              Unaligned cohorts are partitioned into connected homology components (K ≥ 1) strictly where pairwise 5-state Forward-Backward coding beats independent encoding (ΔLhom > 0 nats). In --mode codon, +1/+2 nt frameshifts are repaired when repair achieves strict cohort MDL savings. Each component with m ≥ 2 sequences builds an evolutionary-distance BioNJ guide tree.
            

            
Connected iff ΔL_hom(X, Y) = L₀(X) + L₀(Y) − L_joint(X, Y) > 0 nats

          


          

            

              Stage 2 — Progressive 5-State Profile & Horizon Bubbles
              GlobalFine • CladeLocalFine • LineagePrivate
            

            

              Progressive profile merging tracks fine posterior homology Pfine at every column. Regions where cross-clade residue-level homology falls below the 0.50 horizon do not force random gap-riddled matches: columns stay scoped as CladeLocalFine or LineagePrivate and emit a HorizonBubbleReport quantifying macro-biophysical conservation (Macro-PRIME nats).
            

            
Column Scale: GlobalFine (root) • CladeLocalFine (owner node) • LineagePrivate (1 taxon)

          


          

            

              Stage 3 — Surgical Subsetting & Lossless .hnex Archives
              RLE Collinear Blocks • Standalone Dossier
            

            

              Every inferred component, guide tree, RLE collinear block, scale label, frameshift event, and horizon bubble serializes losslessly into Extended NEXUS (.hnex). Dropping a .hnex file back onto SQUINT reconstructs the entire ledger instantly with zero recomputation, and subset_cached slices exact gene regions (seq:start-end), clades, taxa, or global-core columns.
            

          

        


        

          

            

              

                Zero Empirical Substitution Matrices
                First-Principles Markov Kernels
              

              

                Instead of fitting BLOSUM, LG08, or PAM, amino-acid rates derive strictly from 5 normalized physicochemical coordinates (Kyte-Doolittle hydropathy, Grantham volume, polarity, charge, aromaticity) + 64-codon 1-step mutational accessibility; 61-codon rates derive strictly from universal genetic-code geometry.
              

              
P(τ) = exp(τ Q) • normalized cleanly over K = 20, 61, or 4 states

            


            

              

                Exact Unbanded Path Partition
                Kraft Equality Σ P = 1
              

              

                Standard pair-HMM heuristics miscalibrate when restricted to a diagonal band. SQUINT normalizes its 5-state transducer (Match, Del, Ins, UnalignedX, UnalignedY) by the exact unbanded partition Zpath(LX, LY) and exact single-impulse active-band DP.
              

              
ΔL_pair = −ln Z_joint(X, Y) adjusted to L₀(X) + L₀(Y) (nats)

            


            

              

                Biophysical Coarse Horizon Audit
                Macro-PRIME Gap Conservation
              

              

                When two clades fail fine 1-to-1 residue matching across a divergent loop (e.g., hypervariable Ig/HIV loops or mtDNA D-loop), SQUINT evaluates a 6-class biophysical Dirichlet-Multinomial (or 4-nucleotide composition in DNA mode) across the unaligned left vs. right clade spans.
              

              
Classes: Hydrophobic(AVILM) • Aromatic(FYW) • Polar(STNQ) • Basic • Acidic • Special

            


            

              

                Elias–Rissanen Universal Integer Code
                Exact Parameter-Free Lengths
              

              

                Sequence lengths, indel lengths, and gap coordinates are billed in natural units (nats) under an exact universal integer prior whose discrete survival differences telescope to 1.000000000000 identically.
              

              
p_N(n) = (ln 2 / 2)·[1/ln(n+1) − 1/ln(n+2)], Σ_{n≥0} p_N(n) = 1

            

          

        


        

          

            

              Do my sequences leave my browser?
              100% Client-Side
            

            

              No. All FASTA/NEXUS/PHYLIP parsing, Fixed-Share null scoring, 5-state Forward-Backward homology detection, progressive profile alignment, and `.hnex` subsetting run locally inside your browser tab via Rust WebAssembly (`squint_bg.wasm`). External network requests happen only if you explicitly open `🌐 Fetch` to retrieve public NCBI/ENA/GitHub records.
            

          

          

            

              What is the difference between '-' and '.' in Horizon FASTA?
              Multi-Scale Gap Semantics
            

            

              In `Horizon Gaps (.)` / `.hnex` mode, `-` (or `---`) denotes a genuine insertion/deletion among members inside a shared homology clade (`owner_node_id`), whereas `.` (or `...`) denotes tokens belonging to an unrelated clade across a Coarse Horizon Bubble — making false cross-clade alignment visually impossible to misread.
